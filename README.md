## Описание

WPF-приложение для учета платежей пользователей. База данных — Microsoft SQL Server, три таблицы: `User`, `Category`, `Payment`.

Что умеет приложение:

- авторизация и регистрация пользователей, роли «Пользователь» (User) и «Администратор» (Admin);
- пароли хранятся в базе в виде хэша SHA1;
- после трех неверных попыток входа появляется капча;
- смена пароля;
- страница пользователя: просмотр пользователей, поиск по ФИО, сортировка, фильтр «Только администраторы»;
- страница администратора: добавление, редактирование и удаление пользователей, категорий и платежей (удаление каскадное);
- диаграмма платежей пользователя по категориям (можно выбрать тип диаграммы);
- выгрузка отчета в Word (.docx и .pdf) и в Excel (.xlsx);
- две темы оформления (по Руководству по стилю и своя), выбранная тема сохраняется.

## Как запустить

Нужно: Visual Studio 2022 (разработка классических приложений .NET), Microsoft SQL Server, SQL Server Management Studio, Microsoft Office (Word и Excel — для выгрузки отчетов).

1. Открыть в SSMS файл `db/schema.sql` и выполнить его (F5). Создастся база `DB_Bykov_Payment` с тестовыми данными.
2. Открыть `UP_Bykov_Payment.sln` в Visual Studio.
3. Если SQL Server установлен не как `localhost` (например, `localhost\SQLEXPRESS`), поменять имя сервера в файле `UP_Bykov_Payment/App.config` в строке подключения: `data source=localhost` → `data source=ИМЯ_СЕРВЕРА`.
4. Запустить проект (F5).

Отчеты Word и Excel сохраняются в папку `Отчеты` рядом с exe-файлом программы (`bin/Debug/Отчеты`).
