# UP_Bykov_Payment

Учебная практика УП.01.01. Быков Денис Александрович, группа 4ИСИП-323.

WPF-приложение для учета платежей пользователей. База данных на MS SQL Server, в ней три таблицы: User (пользователи), Category (категории платежей) и Payment (платежи). Подключение к базе через Entity Framework.

## Что сделано

- авторизация и регистрация, две роли: User и Admin
- пароли хранятся в базе в виде хэша SHA1
- капча после 3 неправильных попыток входа
- смена пароля
- страница пользователя с поиском по ФИО, сортировкой и фильтром
- страница администратора: добавление, редактирование и удаление пользователей, категорий и платежей
- диаграмма платежей по категориям
- выгрузка отчета в Word, PDF и Excel
- две темы оформления, выбранная тема запоминается

## Структура

- `db/schema.sql` - скрипт создания базы данных с тестовыми данными
- `res/` - иконка, логотип и картинка для пользователя без фото
- `packages/` - Entity Framework 6.2.0
- `UP_Bykov_Payment/` - сам проект
  - `MainWindow.xaml` - главное окно
  - `Dictionary.xaml` - словарь стилей по руководству по стилю
  - `MyDictionary.xaml` - мой словарь стилей
  - `Model1.edmx` - модель базы данных
  - `Pages/` - страницы приложения (авторизация, регистрация, смена пароля, страница пользователя, страница администратора, таблицы, диаграммы)

## Запуск

1. Выполнить `db/schema.sql` в SQL Server Management Studio.
2. Открыть `UP_Bykov_Payment.sln` в Visual Studio 2022.
3. Если сервер называется не localhost, поменять `data source=localhost` в файле `UP_Bykov_Payment/App.config`.
4. Запустить (F5).

Для выгрузки отчетов нужен установленный Word и Excel. Отчеты сохраняются в папку `bin/Debug/Отчеты`.
